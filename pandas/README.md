## pandas ist die Standardbibliothek in Python zur Datenanalyse.

Damit kannst du:
- Tabellen einlesen
- Daten bereinigen
- filtern
- sortieren
- analysieren
- Statistiken berechnen
- Diagramme vorbereiten
- Daten exportieren

**Installieren**
```bash
pip install pandas
```

Ein üblicher Analyseablauf sieht so aus:   
- Daten laden (read_csv, read_excel)
- Überblick verschaffen (head, info, describe)
- Daten bereinigen (fehlende Werte, Datentypen, Duplikate)
- Filtern und transformieren
- Neue Spalten berechnen
- Gruppieren und aggregieren (groupby, agg)
- Ergebnisse visualisieren (z. B. mit matplotlib oder seaborn)
- Exportieren (to_csv, to_excel)
